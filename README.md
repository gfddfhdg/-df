# 星课it-前端练手项目实训 – 带源码课件

获课：xingkeit.top/18810/前端练手项目实训 – 带源码课件


前端静态页面实训：企业官网、个人博客页面复刻，附带源码与课件

前端静态页面实训的价值，不在于把页面“做得像”，而在于通过复刻完整走一遍需求拆解、结构搭建、样式还原、响应式适配和交付归档的流程。企业官网和个人博客是两类典型页面：前者重信息架构与品牌表达，后者重内容排版与阅读体验。用这两个项目做实训，既能练基本功，也能形成可复用的源码与课件。

一、实训目标：从“照着画”到“能拆能讲”

实训先定四个目标。第一，能看懂设计稿：识别栅格、间距、字号层级、色彩规范和组件复用关系。第二，能拆页面结构：把页面拆成页头、导航、横幅、内容区、侧栏、页脚等语义区块，再拆到卡片、列表、按钮、表单等组件。第三，能还原样式：掌握盒模型、Flex 与 Grid 布局、定位、伪类和过渡动画，保证桌面端还原度。第四，能适配多端：用媒体查询和相对单位完成平板与手机布局，处理导航折叠、图片自适应和文字换行。最后要能讲清楚“为什么这样写”，而不是只交一张看起来差不多的页面。

二、企业官网复刻：先信息架构，再视觉还原

企业官网通常包含首页、产品页、解决方案页、关于我们和联系我们。复刻时先画信息架构图，明确每页的主任务和转化入口，再动手写结构。首页重点练首屏横幅、核心卖点卡片、客户案例和页脚；产品页重点练图文交替、参数表格和行动按钮；联系页重点练表单布局与校验提示。视觉上先统一色彩、字体、圆角和阴影，再逐块还原；不要一边调细节一边改整体，否则返工多。

响应式是企业官网的难点。桌面端多栏布局在手机端要能自然降为单栏，导航要折叠，图片要按容器缩放，表格要能横向滚动或改为卡片。实训要求每个页面至少检查三种宽度，记录断点变化和溢出问题。

三、个人博客复刻：重排版，也重内容结构

个人博客重点练文章列表、文章详情、标签分类、归档和关于页。列表页练卡片布局、摘要截断、时间与标签的层级；详情页练正文排版，包括标题层级、段落行宽、行距、引用、图片说明和代码块样式；归档页练按时间分组和轻量交互。博客不追求复杂动效，而追求阅读舒适：正文行宽适中，对比度足够，目录和返回顶部不抢视线。

实训中要求用同一套样式变量管理颜色、字号和间距，保证列表页与详情页风格一致。交互只做必要项：移动端菜单、标签筛选、返回顶部和图片灯箱，避免为了炫技堆插件。

四、源码与课件组织：让复刻成果可教学、可复用

源码按“公共样式、公共脚本、页面文件、图片资源、字体文件”分目录，企业官网和博客各成独立项目，附一份说明文档，写清页面清单、断点设置、组件复用方式和已知问题。课件按“任务书—设计稿—拆解演示—分步实训—验收标准”组织：任务书讲清交付物；拆解演示展示如何从设计稿划区块；分步实训按页头、首屏、内容区、页脚逐步推进；验收标准包含还原度、响应式、语义化、可维护性和代码规范。课件中保留常见错误对比图，比如间距不统一、图片溢出、移动端横向滚动，方便课堂讲评。

五、验收与避坑

验收看五点：桌面与手机还原度、布局是否稳健、语义标签是否合理、样式是否可复用、控制台有无报错。常见坑包括：直接抄设计稿绝对定位、忽略盒模型导致溢出、图片不设最大宽度、移动端字体过小、类名随意导致样式冲突。实训结束要求每人做一次三分钟讲解，说明结构拆分和响应式思路，把“做过”变成“讲得清”。

静态页面实训的心法是：企业官网练结构与品牌表达，个人博客练排版与阅读体验，源码与课件练交付与教学。复刻不是终点，能拆、能改、能讲，才是前端基本功真正落地。
